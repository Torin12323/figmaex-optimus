# v1.4.3 背景自动铺满

用户截图显示装甲在底部截断并出现大块纯色区。此次取消背景的固定像素高度，改为100%宽和100%高，并给装甲SVG设置preserveAspectRatio="none"，完整适配容器比例。此变换只用于装甲线稿，不作用于用户角色原图。

外壳、右侧和目录区域均适配各自容器。市场结果空白容器改为透明；带文字的链接和空搜索提示仍为实色底。没有修改display、position、width、height、max-height、overflow等布局属性。

background-check-v1.4.3.json记录不同高度和深浅主题的背景绘制、底部颜色采样及改动前后几何比较。测试在本地Chromium中，依据发布包结构模拟，未控制用户真实安装。
