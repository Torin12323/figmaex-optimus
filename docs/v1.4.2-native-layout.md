# v1.4.2 定位结果

来源：官方 Chrome Web Store FigmaEX，扩展 ID dimbmiiiefochhhipipkphcfjckchhjd。以读取方式下载当前发布包 v1.5.101，未安装、未执行发布包 JavaScript。用户截图版本 v1.5.100，仍需区分相邻版本差异。

源码样式：ExBar 为 row-reverse，默认宽54px，expanded宽400px。area-actions宽240px，area-groups宽160px。area-groups 和 GroupPad 是同一元素。顶部header和底部reseize-hand都位于area-actions中。底部原生为 position:absolute。收起不等于隐藏；顶部header的mouseenter触发expand，minMode开启时延迟400ms。

已确认的皮肤问题：覆写reseize-hand为relative改变底部位置；列表height:auto!important破坏原生height:calc(100% - 54px)，与保存的根容器高度产生空白及滚动区错位。两处均撤回。54px本身属于原生折叠，不能当成宽度塌缩的充分证据。

之前预览把header放到外层、目录与GroupPad拆成两层，兼容测试甚至假设目录绝对定位，均与真实发布包不一致。这是前次测试遗漏原因。新增发布包结构测试；仍未操作用户真实安装，不能把模拟成功当作用户已经恢复。

另修复同一元素同时带有 area-groups 和 GroupPad 时，后写的透明 GroupPad 背景覆盖目录深色底的问题。
